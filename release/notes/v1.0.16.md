macOS input preview for the noxhsxrk/remotedisplay fork.

## Changes

- Forward Caps Lock events from a Mac client to a Mac host in Map, Legacy and Translate keyboard modes, including input-source switching taps with uppercase lock off.
- Avoid duplicate Caps Lock injection when the host synchronizes lock state.
- Add native Dock gesture forwarding for switching between Spaces and full-screen apps, retaining gesture progress and cancellation.
- Add handling for the same event family's Mission Control, App Exposé and system pinch gestures.
- Restrict capture to the active remote session, require the host to advertise support, and cancel stale or interrupted gestures.

## Validation and limitations

This is a source preview, not a verified binary release. No DMG assets have been built or attached.

- Native gesture construction/lifecycle tests passed without injecting real input.
- Cocoa gesture capture passed Swift typechecking; the native macOS engine source passed Clang syntax checks.
- Three Caps Lock conversion tests passed in an isolated harness with dependency stand-ins.
- Full Rust/Flutter builds and two-Mac acceptance tests are still outstanding. The current build machine lacks the required Flutter/native dependency setup and generated bridge files.
- Dock gesture forwarding is gated to macOS 14–26 and uses undocumented system event fields. App-specific pinch/rotation and other trackpad gestures are not covered.
- Both the client and server engines must be rebuilt and installed to test these changes. The client needs Accessibility permission for gesture capture.
